# Кыргызча карточки — Android MVP

Проект Android Studio на Kotlin + Jetpack Compose + Room. Приложение работает локально, без регистрации и без интернета.

## Реализовано
- Вставка списка слов и импорт TXT через системный файловый выбор Android.
- Распознавание пар через тире, табуляцию и несколько пробелов.
- Предпросмотр распознанных пар и сохранение наборов в Room.
- Список наборов и удаление набора.
- Карточки: русский текст сначала, кыргызский перевод открывается по кнопке.
- Оценка ответа кнопками; свайпы вправо/влево после открытия перевода.
- Сохранение количества правильных/неправильных ответов и серии правильных ответов.
- Экран итогов занятия, базовый таймер и пауза.
- Работа с кыргызскими символами в UTF-8.

## Открытие и запуск
1. Установите Android Studio (актуальную стабильную версию).
2. Распакуйте ZIP.
3. В Android Studio выберите **Open** и укажите папку `KyrgyzFlashcards`.
4. Дождитесь Gradle Sync. Для сборки нужен JDK 17 и Android SDK Platform 35.
5. Подключите Android-смартфон с включённой USB debugging или создайте эмулятор.
6. Нажмите **Run**.

## Как собрать APK
В Android Studio: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
Обычно файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Импорт
Форматы, которые можно вставить:
```
таштоо — бросать
жудотту    измучил
чынында<TAB>на самом деле
демек - значит, следовательно
```
Сторона до разделителя считается кыргызским словом, после разделителя — русским переводом.

## Честное ограничение текущей версии
Это рабочая стартовая версия (MVP), а не полностью завершённая реализация всего большого технического задания. В частности, здесь ещё нет редактирования отдельных пар после сохранения, переименования набора в интерфейсе, объединения выбранных наборов через экран настройки, экспорта TXT, графика истории, светлой/тёмной настройки и восстановления активной сессии после принудительного завершения процесса. Таймер включён как базовый механизм, но настройки его длительности пока нужно расширить в интерфейсе. Основные сценарии импорта, локального сохранения и прохождения карточек заложены в проекте.

## Сборка APK в облаке без Android Studio (GitHub Actions)
В проект добавлен workflow `.github/workflows/build-apk.yml`. После загрузки файлов проекта в GitHub и запуска Actions сборка выполняется на облачном runner, а APK появляется как artifact `KyrgyzFlashcards-debug-apk`.
